# PromptDeck

PromptDeck is a React Native app for saving, organizing, testing, and improving AI prompts across projects.

## Overview
Developers and creators can store reusable prompts, tag them by model or task, run quick tests, and track which versions perform best.

## Problem
Useful AI prompts get lost in notes apps, chats, and browser tabs.

## Solution
PromptDeck provides a structured, searchable prompt library with version history and quick-copy sharing.

## Features
- Prompt folders and tags
- Variable placeholders
- Prompt version history
- Quick copy and share
- Model-specific notes
- AI prompt-improvement suggestions

## Tech Stack
- React Native + Expo
- TypeScript
- SQLite
- OpenAI API
- Expo Clipboard
- Zod
